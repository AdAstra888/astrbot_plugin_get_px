## 发图

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/p [标签] [数量]` | 按标签搜索并发送图片，支持含空格的多词标签 | `/p 初音ミク 3` |
| `/p [数量]` | 无标签时随机发送图片 | `/p 5` |
| `/p [标签] [数量] [方向]` | 按画面方向筛选，方向可写在任意位置 | `/p 初音ミク 5 横图` |
| `/p #<作品ID>` | 按 Pixiv 作品 ID 直接发送该作品 | `/p #12345678` |
| `/p <Pixiv 作品链接>` | 粘贴作品链接直接发送 | `/p https://www.pixiv.net/artworks/12345678` |
| `/p 收藏 [#<作品ID>]` | 收藏作品；省略 ID 时收藏最近一次成功发送的图 | `/p 收藏` |
| `/p 收藏列表 [数量]` | 查看自己的收藏，默认最近 10 条，最多 50 条 | `/p 收藏列表 20` |
| `/p 取消收藏 [#<作品ID>]` | 取消收藏；省略 ID 时针对最近一次发送的图 | `/p 取消收藏 #12345678` |
| `/p 帮助` | 查看发图指令速查 | `/p 帮助` |

方向可选 `横图`（横屏 / 横向 / 横版 / landscape）、`竖图`（竖屏 / 纵向 / 竖版 / portrait）、`方图`（方形 / 正方 / square）、`不限`（any）。不写方向时按配置 `image_orientation` 的默认值处理，指令里写方向可临时覆盖默认值。方向筛选会同时下发给 Lolicon 的 `aspectRatio` 参数并在本地按宽高比复核，宽高比未知的作品按「不匹配」处理。

凑不够张数时插件会自动扩大候选池并翻页补拉，最多 3 轮；仍然不足会明确回复「请求 N 张，实际发送 M 张」，不会静默少发。

每成功发送一张图片，都会按配置扣除 `p_coin_cost` 金币（`0` 表示免费）；金币不足时仅提醒、不进入取图，图片下载或发送失败不扣币。按作品 ID 发图只发 1 张、同样按张扣费，且不参与去重池——用户点名要的图不会被去重拦下。

图片附带的文案由 `caption_mode` 控制：`full`（默认，标题 + 画师 + 作品链接 + 图源与作品 ID）、`compact`（单行精简）、`off`（仅标题与作品 ID）。图源会标注为「P站（Pixiv）」或「L站（Lolicon）」。

收藏功能由 `favorites_enabled` 控制，收藏数据独立存放、不随去重记录清理。收藏按用户隔离：同一用户在群里和私聊看到的是同一份收藏，不同用户互不可见。收藏本身不扣金币。

发图默认请求 Lolicon；请求失败或无结果时，有标签回退 Pixiv 搜索，无标签回退 Pixiv 推荐作品。Pixiv 回退仅在配置 `pixiv_refresh_token` 后可用。

普通发图与正式签到背景共享图片去重索引。`dedupe_days` 可设置最近 `0–7` 个北京时间自然日；同群成员共享去重，不同群、私聊用户、标签和图片源相互隔离。Lolicon 图片地址不可用时，可在 `lolicon_image_proxy_origins` 中按行配置多个图片反代 origin；该配置不代理 Lolicon API 或 Pixiv 登录。

## 签到（管理员）

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/签到管理 预览` | 使用当前用户资料和问候配置预览卡片，不写入数据 | `/签到管理 预览` |
| `/签到管理 事件查看` | 查看全局签到事件 | `/签到管理 事件查看` |
| `/签到管理 事件添加 <年度\|单次> <日期> <名称>` | 添加年度或单次全局事件 | `/签到管理 事件添加 年度 07-11 相遇纪念日` |
| `/签到管理 事件删除 <ID>` | 按事件 ID 删除全局事件 | `/签到管理 事件删除 1` |
| `/签到管理 导出` | 管理员导出签到完整备份 | `/签到管理 导出` |

只输入某个指令组名（如 `/签到生日`、`/签到排行`、`/签到商店`、`/签到主题` 或 `/签到管理`）时，AstrBot 会显示对应层级的文字指令树；使用 `/签到帮助` 发送完整帮助图。文档使用默认前缀 `/`；实际前缀以 AstrBot 的 `wake_prefix` 配置为准。

## 自然语言触发

开启 `auto_trigger_enabled` 后，可以不带命令前缀触发搜图。自然语言触发的搜图与 `/p` 共用发图与扣费流程，成功发图同样按 `p_coin_cost` 每张扣币。

| 触发语 | 效果 |
| --- | --- |
| `来一份图` | 发送 1 张随机图片 |
| `大肥鱼来张图` | 称呼在前也认得出来；`大肥鱼` 是机器人称呼时忽略，否则当标签 |
| `来三张初音ミク图` | 搜索「初音ミク」并发送 3 张 |
| `来十二张初音图` | 支持「十二」「二十」「俩」等中文数量 |
| `来张初音图 竖图` | 搜索「初音」并只要竖图；方向词不会混进标签 |
| `来张#12345678` | 按作品 ID 直接发送 |
| `签到` | 触发每日签到（走签到指令，不走发图） |

判定规则：

- **称呼识别**：句子开头的「大肥鱼」如果命中机器人称呼（配置项 `checkin_bot_name` 或 `auto_trigger_aliases`），就当作在叫机器人，从标签里剔除；没命中就当作搜索标签，所以 `初音来张图` 仍然搜「初音」。
- **标签清洗**：句尾的「的」、句首的「给我」「帮我」「请」等客套词、以及「福利」「涩」这类语气词都不会进标签。
- **不误触发**：描述已经发生的事（含「了」「过」「昨天」）、提问（问画师、问出处、句尾问号）不会触发，也不会送去模型。
- **模型兜底**：规则认不出的句子，在 `auto_trigger_ai_fallback` 开启时会交给当前会话的模型抽成结构化参数（标签、张数、方向、作品 ID）。同一句被模型判定为「不是在要图」后会被记住，不重复调用。模型调用超时或失败时静默放过，消息继续交给其他插件处理。
